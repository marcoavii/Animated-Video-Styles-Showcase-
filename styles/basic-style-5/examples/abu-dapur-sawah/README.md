# Contoh: abu dapur ke sawah (9 detik, 9:16)

VO: "Pak Darto menebar abu dapur ke sawahnya setiap pagi. [tawa] Tetangga bilang dia cuma buang-buang waktu. Tapi waktu panen, padinya paling tinggi di desa!"

- 4 shot: menebar abu (dorong), tetangga tertawa (hard cut tepat di tawa), dissolve ke panen (tarik), Darto merentangkan tangan (dorong, DOF tipis).
- Sawah = dua `pond()` dangkal (`depth: 0.32, level: 0.78`) + `rice()`; padi muda `{ h: 0.38 }`, panen `{ h: 1.35, ripe: 1 }`.
- Abu: `pellets(..., 0x9c9a94, 0.8)` digerakkan manual ke arah petak (lihat shot s1).
- Tawa dari tag ElevenLabs `[chuckles]` tidak ada di script; waktunya dicari dari energi VO (2,86-3,26 s) dan dipakai sebagai titik cut.
