# Basic style 1

Pintasan ke gaya 1 di skill gabungan `basic-style`. Gayanya sudah dipilih, jadi **jangan tanya gaya lagi**. Rasio selalu 9:16.

1. Cari folder skill `basic-style` di sebelah folder skill ini (biasanya `~/.claude/skills/basic-style`).
2. Baca bagian "Aturan bersama" di `basic-style/SKILL.md`.
3. Baca `basic-style/styles/basic-style-1/STYLE.md` sampai habis dan ikuti alur kerjanya persis. Di file itu, `SKILL` berarti folder `basic-style/styles/basic-style-1`.

Kalau folder `basic-style` tidak ada, minta user menjalankan installer repo (`setup/install.ps1` di Windows, `setup/install.sh` di Mac/Linux).
